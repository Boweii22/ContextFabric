How It Works

A private memory pipeline, not another chatbot.

ContextFabric uses Gemma 4 for real product work: extraction, conflict detection, source-grounded answering, and app-specific context assembly.

1

Import your sources

Add project folders, GitHub repos, ChatGPT exports, Claude exports, markdown, PDFs, and notes.

2

Gemma 4 extracts memory

The local model turns messy text into project, style, decision, preference, and person nodes.

3

You approve access

Apps request context scopes. You grant one hour, this session, always, or deny.

4

Context follows you

The extension injects approved context into AI tools without sending your memory to a cloud database.

Why Gemma 4

The model is the memory engine.

ContextFabric uses Gemma 4 locally because personal context is exactly the kind of data that should stay on your machine. The model reads long, messy sources and converts them into structured graph memory that other tools can use safely.

  • Extracts typed memory nodes with confidence scores.
  • Detects contradictions before new memories are accepted.
  • Assembles concise payloads for Claude, ChatGPT, Cursor, and generic tools.
  • Works offline after the model is installed, proving the privacy claim.
